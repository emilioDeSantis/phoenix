# Phoenix Construction Resources — Website

New website and brand for Phoenix Construction Resources, a Massachusetts staffing company that supplies skilled carpenters and laborers to general contractors.

**Live:** https://phoenix-six-mu.vercel.app

## What I did

- Designed the new logo and site, with a focus on getting contractors to request a crew
- Built a 3D phoenix animation with Three.js and React Three Fiber, with physics and scroll-driven motion
- Built partner and job application flows for contractors and workers

## Stack

Next.js · TypeScript · Three.js · React Three Fiber · GSAP · Lenis smooth scroll · Tailwind CSS · Vercel
